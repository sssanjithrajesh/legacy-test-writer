# Legacy Test Writer

**Type:** 48-hour prototype.
**Target roles:** Solutions / Applied AI Engineer at labs, enterprise-services partner channels.

An agent that reads a module from a small open-source legacy codebase (COBOL or old Java) and
generates characterization tests. Coverage is measured before and after.

## Deliverables

- Module reader and test generator
- Coverage report: baseline vs. after
- Write-up: where the generated tests were wrong and how that was caught
